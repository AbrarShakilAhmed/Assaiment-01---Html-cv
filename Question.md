# Assaiment-01---Html-cv

HTML Practical Question — Create a CV

Question:
Create a Personal CV/Resume webpage using only HTML.

Your CV must contain the following sections:

1. Personal Information:

Full Name
Profile Picture
Email
Phone Number
Address

2. Career Objective:
Write a short career objective of 3–4 lines.

3. Education:
Create a table containing:

Degree
Institution
Passing Year
Result

4. Skills:
Create a list of your technical and soft skills.

5. Work Experience:
Add at least 2 work experiences with:

Company Name
Position
Duration
Responsibilities

6. Projects:
Add at least 2 projects with project name and short description.

7. Languages:
Mention the languages you know and your proficiency level.

8. Personal Information:
Include:

Father's Name
Mother's Name
Date of Birth
Nationality
Religion
Marital Status

9. References:
Add at least one reference with:

Name
Position
Organization
Email
Phone
Requirements
Use only HTML.
Use proper semantic HTML elements such as <header>, <main>, <section>, <table>, <ul>, <ol>, etc.
Use a <table> for the Education section.
Use lists for Skills and Languages.
Use headings properly: <h1>, <h2>, <h3>.
Add a profile image using <img>.
Add links using <a>.
Do not use CSS or JavaScript.
